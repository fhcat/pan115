# pan115 — CLI Design Spec

**Date:** 2026-06-21  
**Status:** Approved

## Summary

A cross-platform Python CLI that replicates the core functionality of the acgotaku/115 Chrome extension: given a 115.com folder CID or file pickcode, it fetches aria2-compatible download links and writes them to an aria2 input file.

## Architecture

```
src/pan115/
  crypto.py   — Port of secret.js (RSA-PKCS1 + XOR + MD5 key derivation)
  api.py      — Client115: cookie loading, file listing, ProAPI download URL
  aria2.py    — Formats FileInfo list → aria2 input file
  cli.py      — Typer CLI entry point
tests/
  test_crypto.py
  test_aria2.py
  test_api.py
```

## CLI Interface

```
115 folder <cid> [--cookies PATH] [--output PATH] [--delay MS]
115 file <pickcode> [--cookies PATH] [--output PATH]
```

Defaults: `--cookies cookies.txt`, `--output aria2.conf`, `--delay 300`.

## Authentication

Netscape cookie file (Cookie-Editor format with `#HttpOnly_` prefix).  
Custom parser strips the prefix before loading into `requests.Session`.

## API Calls

- **File listing:** `GET webapi.115.com/files?aid=1&limit=1000&show_dir=1&cid=<cid>`
- **Download URL:** `POST proapi.115.com/app/chrome/downurl?t=<ts>` with encrypted pickcode body

## Crypto

Port of `secret.js`:
- Key derivation: `hashlib.md5(f"!@###@#{ts}DFDR@#@#".encode()).digest()`
- `sym_encode` / `sym_decode`: XOR with static `kts`, `keyS`, `keyL` tables
- `asym_encode` / `asym_decode`: RSA with hardcoded public key via `pow(m, e, n)`

## Output Format

```
<url>
  out=<folder/path/filename>
  header=User-Agent: <ua>
  header=Referer: https://115.com/
  header=Cookie: acw_tc=<value>
  checksum=sha-1=<sha1>

```

## Dependencies

`requests>=2.31`, `typer>=0.12`

## Testing

- `test_crypto.py`: round-trip encode/decode
- `test_aria2.py`: fixture FileInfo → assert output lines
- `test_api.py`: mocked HTTP with `responses` library
